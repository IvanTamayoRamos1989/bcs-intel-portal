# Deploy — phone shell, third pass

## What changed

The phone remembers the last tab for this visit. A reload opens Consulta, Mapa or Archivos where you left it. The wide window still opens all three together.

The line “El mapa ya muestra ese lugar” appears only when the answer names a place the map can frame. A general question stays in Consulta. Archivos still shows how many files belong to the answer. When the phone does move to Mapa, that tab flashes blue once. There is no vibration.

On the phone, only three suggested questions stay above the box, each on two lines. The voice hint is hidden there so the conversation has the height.

A file preview has Cerrar vista. Lists and the chat do not drag the page when you reach their end.

The map is still only Baja California Sur.

## How to verify

1. At about 390×844, open Archivos and reload. Archivos is still the tab.
2. From Consulta, ask something with no place. You stay in Consulta and there is no map line.
3. Ask about Presa El Novillo. The phone goes to Mapa, the tab flashes, and Archivos counts the file.
4. Open that file and close the preview. At about 844×390 the names are still a side rail.
