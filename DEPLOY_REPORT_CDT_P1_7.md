# Deploy — Phase 1.7 saved views, open questions, print list

## What shipped

### `/vistas`
Five named links. Each one reuses a scenario or layer list that already exists. Nothing new is stored server-side.

| View | Map | Twin |
|---|---|---|
| Agua primero en el sur | `/mapas?scenario=water_first#gis` | Housing theme, population × poverty |
| Crecimiento Cabos–La Paz | `/mapas?scenario=corridor_intensify#gis` | Mobility theme, population × cruise calls |
| Puertos y aeropuertos | `/mapas?scenario=ports_air_hubs#gis` | Mobility theme, population × cruise passengers |
| Contexto de vivienda | Settlements, POER units, deficit-aquifer markers | Housing theme, SNIIV 2025 × poverty. CONAVI backlog stays statewide |
| East Cape y áreas protegidas | East Cape focus plus federal protected areas | Urban theme, Los Cabos, population × localities |

### `/metas`
Strategic questions grouped by the five twin themes, status **abierta**. Foresight signals, status **en el portal**, with the theme already on the signal. Twelve data gaps, status **evidencia parcial** or **brecha abierta** as the list already records (8 partial, 4 open). No progress percentage.

### Print
`/gemelo` print hides site chrome and map controls, keeps the quality strip, and lets the side panel flow. `/aprendizaje` print shows only the one-page external shortlist (GPSC, UrbanShift, C40, ICLEI, USE, CEPAL, World Bank urban overview, Aqueduct, MapBiomas, Resource Watch, DataMéxico, Data Commons).

### Discovery
Specialists menu and header search include vistas and preguntas abiertas, in Spanish and English. The consultation chat links to vistas, metas, coordination, and `/aprendizaje#evidencia`. Corpus chunk `portal:vistas-metas-p17` explains them and ends with a follow-up question. Library and catalog link the new pages.

## How to try

1. `/vistas/` then “Abrir en mapas” on Puertos y aeropuertos.
2. `/metas/` and confirm there is no percent-complete column.
3. Print `/aprendizaje/` and check that only the short external list remains.
4. On `/inicio`, use Vistas guardadas or Preguntas abiertas.
