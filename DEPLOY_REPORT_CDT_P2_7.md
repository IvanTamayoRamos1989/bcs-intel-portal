# Deploy — Phase 2.7 fiche frames and height legend

## What shipped

- The municipality fiche on `/gemelo` shows up to three territory frames already catalogued for that municipality’s saved view. The caption is the place name. A tap opens that view. If the municipality has no frame, the strip is left out.
- Next to the height control, a short legend names the figure, the unit, the source and the year. A blank cell stays flat. It is not zero.
- On a phone the fiche folds, so the map stays on the page.

`public/stills/` is gitignored and must stay on the deploy machine. This phase adds no image files.
