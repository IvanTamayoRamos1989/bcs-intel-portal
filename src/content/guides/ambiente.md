Áreas Naturales Protegidas (ANP) federales principales en BCS. Cifras de decretos / programas de manejo y capa CONANP–CONABIO 2025.

## Cuatro ANP de referencia

### Reserva de la Biosfera El Vizcaíno

| | |
|---|---|
| Decreto | DOF **30 nov 1988** (PM también cita 5 dic 1988) |
| Superficie | **2,546,790.25 ha** |
| Municipio | Mulegé (~77% del municipio según PM) |
| Núcleos | 16 zonas núcleo (~363 mil ha según localización del PM) |
| Patrimonio | UNESCO 1993: refugio de ballenas (lagunas) y pinturas rupestres Sierra de San Francisco |

### Reserva de la Biosfera Sierra La Laguna

| | |
|---|---|
| Decreto | DOF **6 jun 1994** |
| Superficie | **112,437.07 ha** (toda terrestre) |
| Ubicación | Sur de La Paz / norte de Los Cabos |
| Núcleo | ~32,520 ha — el PM la describe como recarga principal de acuíferos del sur del estado |

### Parque Nacional Cabo Pulmo

| | |
|---|---|
| Decreto | DOF **6 jun 1995** |
| Superficie | **7,111.01 ha** (~99% marina) |
| Municipio | Los Cabos |
| Nota | Único arrecife coralino del Golfo de California (intro PM) |

### Parque Nacional Bahía de Loreto

| | |
|---|---|
| Decreto | DOF **19 jul 1996** |
| Superficie | **206,580.75 ha** |
| Municipio | Loreto |
| PM actualizado | Resumen DOF **23 abr 2019** |

## Otras ANP en la capa federal 2025 (BCS)

| Nombre | Categoría | ha | Decreto |
|---|---|---:|---|
| Cabo San Lucas | APFF | 3,996.05 | 1973-11-29 |
| Balandra | APFF | 2,512.73 | 2012-11-30 |
| Loreto II | PN | 6,217.52 | 2023-08-15 |
| Nopoló | PN | 2,076.52 | 2023-08-15 |

También aparecen polígonos **bi-estatales** (BC y BCS): Complejo Lagunar Ojo de Liebre e Islas del Pacífico de la Península. No se deben atribuir superficies del norte a BCS.

Las ANP son **restricciones de uso** sobre cualquier régimen de tenencia subyacente; no son un tipo de propiedad por sí solas.

Main federal Protected Natural Areas (ANP) in BCS. Figures from decrees / management programs and the CONANP–CONABIO 2025 layer.

## Four reference ANPs

### El Vizcaíno Biosphere Reserve

| | |
|---|---|
| Decree | DOF **30 Nov 1988** (management program also cites 5 Dec 1988) |
| Area | **2,546,790.25 ha** |
| Municipality | Mulegé (~77% of the municipality per management program) |
| Core zones | 16 core zones (~363k ha per PM location notes) |
| Heritage | UNESCO 1993: whale refuge (lagoons) and Sierra de San Francisco rock art |

### Sierra La Laguna Biosphere Reserve

| | |
|---|---|
| Decree | DOF **6 Jun 1994** |
| Area | **112,437.07 ha** (all terrestrial) |
| Location | South of La Paz / north of Los Cabos |
| Core | ~32,520 ha — PM describes it as the main aquifer recharge for the south of the state |

### Cabo Pulmo National Park

| | |
|---|---|
| Decree | DOF **6 Jun 1995** |
| Area | **7,111.01 ha** (~99% marine) |
| Municipality | Los Cabos |
| Note | Only coral reef in the Gulf of California (PM intro) |

### Bahía de Loreto National Park

| | |
|---|---|
| Decree | DOF **19 Jul 1996** |
| Area | **206,580.75 ha** |
| Municipality | Loreto |
| Updated PM | DOF summary **23 Apr 2019** |

## Other ANPs in the 2025 federal layer (BCS)

| Name | Category | ha | Decree |
|---|---|---:|---|
| Cabo San Lucas | APFF | 3,996.05 | 1973-11-29 |
| Balandra | APFF | 2,512.73 | 2012-11-30 |
| Loreto II | PN | 6,217.52 | 2023-08-15 |
| Nopoló | PN | 2,076.52 | 2023-08-15 |

**Bi-state** polygons (BC and BCS) also appear: Complejo Lagunar Ojo de Liebre and Pacific Islands of the Peninsula. Do not attribute northern areas to BCS.

ANPs are **use restrictions** over any underlying tenure regime; they are not a property type by themselves.

### Frequent spatial locks

- ANP cores (`const_anp_nucleos`) — East Cape / Cabo Pulmo especially sensitive.
- POER conservation / sustainable-use UGAs before claiming “available land”.
- PSDU Barriles sanitation as a proxy for local environmental infrastructure.
