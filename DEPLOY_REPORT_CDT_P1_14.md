## Loreto 2025 air travelers — wired

Official page, opened 31 October 2026: [Gobierno de Baja California Sur](https://www.bcs.gob.mx/supera-bcs-los-4-5-millones-de-pasajeros-aereos-en-2025-la-paz-crece-10-9/). The tourism secretary states:

- State total: 4,523,400 passengers
- Los Cabos: 3,765,000 passengers
- La Paz: 668,800

Not used: Wikipedia and a secondary airport page cite AFAC for 183,381 passengers in 2025. The AFAC spreadsheet was not opened, so that number is not in the twin. Comondú and Mulegé have no airport, so air passengers stay off the five-municipality chart. The gap on `/metas` is now partial: the state release is cited, and the AFAC file is still missing.
