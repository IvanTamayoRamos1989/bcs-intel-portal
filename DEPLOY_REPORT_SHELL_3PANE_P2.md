# Deploy — 3-pane shell, second pass

## What changed

`/inicio` is still the window after login. This pass tightens the three panes. `/gemelo` stays the long board.

- **Files from the answer.** “De esta respuesta” reads the question, the answer text, and the titles of the files the chat cited. A file has to share a real word with that text, or be the same link. Common words do not fill the list.
- **Folders.** Every folder lists the files it actually has. Fotogramas opens by municipality. A search that finds many files shows the first sixty and a button for the rest.
- **More places, only published points.** Santo Domingo is the town in Comondú; aquifer 0306 has no polygon. The Puerto San Carlos levee is a news item, not a layer. The CFE solar plants, including El Crucero, have no published site: the map uses the inventory marker and says so. OOMSAPAS Los Cabos uses the desalination point already in the inventory, which is the municipality, not the office. OOMSAPAS La Paz frames the municipality because there is no plant coordinate.
- **Panes.** Each divider has a Consulta or Archivos button that folds that pane. Dragging the divider still changes the width.

## How to verify

1. Ask about Presa El Novillo. The map marks the La Paz inventory point and the file list leads with the Novillo document.
2. Ask about the Santo Domingo aquifer, or about OOMSAPAS. The note on the map says what the point is, and the files match that name.
3. Open Fotogramas and a municipality inside it. Search a file name and, if the list is long, use the button for the rest.
4. Fold Consulta, then open it again. The map fills the space that was left.

No new AGEB, cadastre, morphometric or climate layer. Blank fiscal cells stay blank.
